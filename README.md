# Chess

Game Platform:- 

A platform where users can create or join a match, play moves in real-time similar to a chess Game.


Features

Match Creation: Users can create a new match or join an existing match.
Real-Time Gameplay: Players can make moves in real-time.

Tech Stack 
Frontend: React (with TypeScript) 
Backend: Node.js (with TypeScript) 
WebSocket: Separate WebSocket server to handle real-time gameplay
